Grant Grinder / Systems

Use one funding desk everywhere.

The toolbar button opens the complete Grant Grinder search app, including your signed-in favorites, saved searches, and previous searches.

Keep the official URL for normal use. Developers can point the extension to http://localhost:5173/search.

Privacy boundary

The extension opens this URL and can pass text you explicitly select as a search query. It does not read pages, inject scripts, or store an API key.
