# Grant Radar browser extension privacy notice

Effective August 10, 2026.

Grant Radar stores the configured API URL and optional API key in browser sync storage. A highlighted phrase selected through the context menu is held briefly in browser session storage and sent to the configured Grants API as a search query when the user requests the search.

The extension does not read full page contents, browsing history, form data, passwords, or unrelated tabs. It does not inject scripts into webpages. Search terms and request metadata may be processed and retained by the configured API according to that service's policy.

Removing the extension removes its local and session storage according to browser behavior. Users can clear or replace API settings from the extension options page.
